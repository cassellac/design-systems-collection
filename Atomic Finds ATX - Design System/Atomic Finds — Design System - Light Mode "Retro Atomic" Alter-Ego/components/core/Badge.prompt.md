One-line: a small uppercase pill for statuses, editions, and counts, always bounded by a thick ink stroke.

```jsx
<Badge tone="yellow">Mint</Badge>
<Badge tone="rust">Fresh Drop</Badge>
<Badge variant="outline">Pressing 001</Badge>
```

Tones: `yellow` / `ink` / `rust` / `teal` / `cream`. `variant="outline"` drops the fill. `shape="rounded"` for a squarer chip.
