One-line: renders a single glyph from the substituted Lucide set, tinted to any color via CSS mask (2px stroke to match UI borders).

```jsx
<Icon name="search" />
<Icon name="disc-3" size={28} color="var(--rust-500)" />
```

`name` is any Lucide icon id. This is a documented substitution — see readme ICONOGRAPHY. Replace the base URL with a local sprite when the real glyph set arrives.
