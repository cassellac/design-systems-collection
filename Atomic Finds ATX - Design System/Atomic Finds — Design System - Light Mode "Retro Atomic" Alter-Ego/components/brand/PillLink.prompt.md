One-line: a floating text link wrapped in a thick 3px pill border that fills yellow and lifts on hover.

```jsx
<PillLink href="/shop">Browse the Crates</PillLink>
<PillLink tone="rust">Sold Out</PillLink>
```

Use for nav items, footer links, and standalone "read more" affordances — anywhere a bare link needs to feel anchored. Tones: `ink` / `yellow` / `rust`.
