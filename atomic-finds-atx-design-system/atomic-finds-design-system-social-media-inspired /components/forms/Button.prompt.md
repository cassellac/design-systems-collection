# Button
Pill-shaped primary/secondary/ghost button — the brand's main call-to-action shape.

```jsx
<Button variant="primary">DM to shop</Button>
<Button variant="secondary" size="sm">Save</Button>
<Button variant="ghost" disabled>Sold out</Button>
```

Variants: `primary` (sun-orange), `secondary` (avocado-green), `ghost` (outlined). Sizes: `sm` | `md` | `lg`.
