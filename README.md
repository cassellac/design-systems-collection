# Master Design Systems Collection

A curated repository of 3 comprehensive design systems featuring UI component specs, token architecture, brand guidelines, and production-ready HTML/CSS templates.

---

## 🎨 Included Design Systems

### 1. [AllyCMS Design System](file:///Users/cuus/Downloads/Design%20Systems/ally%20cms%20Design%20System/index.html)
- **Domain**: Admin Dashboards & Editorial Content Management System
- **Theme**: Pulse Blue (`#3A7BD5`), Signal Red (`#C5301A`), Bone White (`#F9F6F0`), Charcoal (`#2D2D2D`)
- **Typography**: Lexend Deca + JetBrains Mono
- **Key Features**:
  - Modular block panels & page layout editor specs
  - 8 full-page administrative templates (Dashboard, Press Office, Research Notes, Page Editor, Settings, Login, Projects, Collections)
  - Color, neutral, spacing, and component guidelines

### 2. [Atomic Finds ATX Design System](file:///Users/cuus/Downloads/Design%20Systems/Atomic%20Finds%20ATX%20-%20Design%20System/index.html)
- **Domain**: E-Commerce, Vintage Rattan & Cosmic Discovery Platform
- **Theme**: Celestial Yellow (`#F5C842`), Amber Orange (`#D4822A`), Deep Charcoal (`#1E1E1E`)
- **Typography**: Bagel Fat One, Agbalumo, Pacifico, DM Sans
- **Key Features**:
  - Orbiting Galaxy Cards with interactive detail dialogs
  - Whimsical mascot curator characters & starry galaxy background utilities
  - Live Supabase product tables & filterable product grids
  - Production homepage kit (`/ui_kits/website/index.html`)

### 3. [Healthcare Training Center (Caladrius) Design System](file:///Users/cuus/Downloads/Design%20Systems/Healthcare%20Training%20Center%20-%20Design%20System/index.html)
- **Domain**: Enterprise Healthcare, Medical Compliance & Learning Platform
- **Theme**: Deep Navy (`#1E3A6E`), Teal (`#2B8FA9`), Amber (`#C9973A`), + 5 Room Identity Colors (CS, HIPAA, Compliance, Records, Finance)
- **Typography**: Montserrat, Inter, Playfair Display
- **Key Features**:
  - Interactive room door cards & completion certificate generator
  - Custom instructor illustration cast & Phosphor icon library
  - Interactive Learner App UI kit (`/ui_kits/learner-app/index.html`)
  - Full Marketing Landing Page (`/Healthcare Training Center - Marketing Site.html`)

## 🚀 Quick Start

Open the central hub in any browser:
```bash

```

Or serve locally with any static web server:
```bash
npx serve .
```
